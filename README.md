# Reisekarte

Interaktive Weltkarte: besuchte Länder markieren, ins Land zoomen, Städte und Dörfer eintragen.

- Eine einzige Datei: `index.html`
- Einträge werden im Browser gespeichert (localStorage), mit Sicherung per Kopieren/Einlesen.
- Kartendaten: Natural Earth (gemeinfrei) über world-atlas, vorprojiziert.
